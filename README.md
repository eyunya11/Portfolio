# ポートフォリオ

公開ページ: https://eyunya11.github.io/Portfolio/index.html

[Astro](https://astro.build/) で作成し、GitHub Pages で公開している個人ポートフォリオ(第1版)。

## 開発

```bash
npm install      # 初回のみ
npm run dev      # http://localhost:4321/Portfolio/ で確認
npm run build    # dist/ に HTML/CSS を出力
```

## 構成

```
src/
  data/profile.ts        ページの中身(文章・作品・スキル)。ここだけ編集すればよい
  pages/index.astro      トップページ(セクションの並び。作品はカードの一覧)
  pages/works/[id].astro 作品の詳細ページ。works 1件ごとに /works/<id>/ を生成
  components/            ヘッダー、フッター、作品の一覧カードと詳細、画像の拡大表示
  layouts/Base.astro     <head> まわり
  styles/global.css      配色・共通スタイル
public/
  images/<作品id>/01.png スクリーンショット
.github/workflows/deploy.yml  main に push すると GitHub Pages に公開
```

## 中身の編集

1. `src/data/profile.ts` の「【要記入】」「【要確認】」を書き換える。
2. スクリーンショットは `public/images/kadai04/01.png` のように置き、`src` を `'images/kadai04/01.png'` に変える。
   - ファイル名・フォルダ名には日本語やスペースを使わない。
3. 作品の `short` は、一覧のカードに出す一言説明。`summary` 以下は詳細ページに出る。
4. 作品のリンク(`url`)を空のままにすると、ページ上では「リンク未設定」と表示される。提出前にすべて埋めること。

## 配色の設計

「メディアデザイン入門」の第1回(明視性・可読性・識別性)と第4回(カラーコーディネート)の内容をもとに決めた。
エディトリアル系のファッションサイトに見られる、白黒だけで構成する硬質なモノクロームをベースにしている。

### 配色の方針

- **白と黒の2色を基本にする**: 無彩色どうしの組み合わせなので、色相がぶつからず統一感が出る。明度差が最大(21:1)なので、明視性も最も高い。
- **差し色は赤1色だけにする**: 無彩色の中に高彩度の色を1色だけ置くと、そこに強く目が行く(アクセントカラーの考え方)。赤はセクション番号、フォーカス枠など、見てほしい所だけに使う。
- **面の切り替えで区切る**: 影やグラデーションは使わない。ヒーロー・凡例・フッターは黒い面、それ以外は白い面にして、白と黒の面の対比で情報のまとまりを示す。

| 役割 | 色 | 使いどころ |
| --- | --- | --- |
| ベース | `#ffffff` 白 | ページの背景 |
| メイン | `#000000` 黒 | 文字、ボタン、ヒーロー・フッターの面 |
| サブ | `#222222` | 日付などの補足の文字 |
| アクセント | `#c8102e` 赤 | セクション番号、リンク未設定の表示、フォーカス枠、リンクのホバー |

### 文字と背景のコントラスト比

| 組み合わせ | 比 | 基準 |
| --- | --- | --- |
| 黒 `#000000` / 白 | 21.00 | AAA (7:1) |
| `#222222` / 白 | 15.91 | AAA (7:1) |
| 赤 `#c8102e` / 白 | 5.88 | AA (4.5:1) |
| 赤 `#c8102e` / 黒 | 3.57 | 基準に届かないため、**赤は黒い面の上では使わない** |

### 可読性への配慮

- 本文は 15〜16px、行間 1.8 にした。参考にしたデザインは本文 10px・行間 1.2 だが、日本語の長い文章を読んでもらうページなので、読みやすさを優先した。
- 英語の大見出し(ABOUT, WORKS など)は行間 1.03 と詰めて、見出しの塊として目に入るようにした。
- 和文には `font-feature-settings: "palt"`(プロポーショナル字詰め)をページ全体にかけている。

### 識別性への配慮

- リンクには色だけでなく下線を付け、色が見分けにくい人でもリンクだと分かるようにした。
- スキルのレベルは色の濃淡ではなく、塗りつぶした四角の数(■■□)と「Lv.2」という文字で示している。
- 「リンク未設定」は、赤い色に加えて点線の枠でも示している。

## 使用素材

- スキルのアイコン: [skill-icons](https://github.com/tandpfun/skill-icons) (MIT License, © 2022 tandpfun)。使う分だけ `public/icons/` に置いている。ライセンス全文は `public/icons/LICENSE.txt`。
  - アイコンを足すときは、上のリポジトリの `icons/` から SVG を取ってきて `public/icons/<名前>.svg` に置き、`profile.ts` のスキルに `icons: ['<名前>']` を書く。白背景なので `-Light` 版を使う。
